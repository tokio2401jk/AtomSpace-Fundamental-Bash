Домашнє завдання з курсу AtomSpace Fundamental, виконав Клебанов В'ячеслав.

Завдання:
1. Створити папку ~/scripts.
2. Створити скрипт log_backup.sh, що створює папку ~/log_backup, копіює всі .log з /var/log/ туди та виводить повідомлення про успішне завершення.
3. Створити скрипт system_check.sh, що виводить навантаження CPU, пам'ять та аптайм.
4. Створити скрипт greet.sh, що питає ім'я і виводить персональне привітання з поточною датою.

Усі скрипти можна знайти у відповідній папці scripts.
Усі скріншоти виконання скриптів можна знайтиу відповідній папці screenshots
